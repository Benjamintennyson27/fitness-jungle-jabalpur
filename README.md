# Fitness Jungle — Jabalpur

Dark-mode, single-page marketing site for Fitness Jungle in Jabalpur, India — part of a batch of premium landing pages built for local gyms.

## Stack

A single `index.html` — vanilla HTML, CSS and JavaScript. No build step, no dependencies.

## Run locally

```bash
npx serve .
```

or just open `index.html` in a browser.
